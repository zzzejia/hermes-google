Hermes Google

Hermes Google is a private, single-user tool. It lets the owner's own assistant bots, which run on the owner's computer, read and update the owner's Google Calendar, read the owner's Gmail and save email drafts, and search, read and create files in the owner's Google Drive, when the owner asks them to.

It is not offered to the public. It cannot send email; drafts are sent by the owner.
